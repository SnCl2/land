# Aurelian Estates

A premium landing page for luxury land investments. Featuring modern styling, glassmorphism, responsive navigation drawer, and dynamic entrance animations.

## Key Features

- **Strategic Overview**: Modern layout highlighting land pricing, strategic advantages, connectivity, and development readiness.
- **Responsive Header & Navigation**: Customized layout displaying a clean single-line header and compact actions on mobile viewports.
- **Slide-out Navigation Drawer**: A responsive glassmorphic navigation drawer for mobile.
- **Floating Action Bars**: Interactive floaters showcasing desktop and mobile social media links.
- **Dynamic Entrance Animations**: Smooth fade-in, slide-down, and slide-up animations on load.
- **Seamless Contact Actions**: Active linking to call services and WhatsApp support.
